# Decisões de arquitetura

Registar aqui decisões estruturais quando forem tomadas; não preencher retroativamente com justificações inventadas. Usar nomes como `0001-titulo-da-decisao.md` e ligar a decisão à tarefa ou proposta correspondente.

Cada registo deve incluir:

- Título, data e estado: proposta, aceite, rejeitada ou substituída.
- Contexto, problema e restrições.
- Alternativas consideradas e respetivas consequências.
- Decisão e motivo, distinguindo factos de suposições.
- Impactos, forma de validar e condições para reavaliar.
- Responsável e aprovação quando necessária.

Quando uma decisão mudar, preservar o histórico e referenciar a que a substituiu. Uma decisão proposta não autoriza a execução de ações que dependam de aprovação.
